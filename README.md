# AI-Based Asthma Risk Prediction System

## 🚀 Project Overview
This project predicts asthma attack risk before it happens by combining:
- Environmental data (AQI, temperature, humidity)
- User profile (age, triggers like dust, cold)
- Real-time symptoms (cough detection)

The system provides early warnings to help users take preventive action.

---

## 🧠 Features
- AI-based risk prediction (Low / Medium / High)
- Location-based AQI integration
- Real-time environmental monitoring
- Symptom-based analysis (cough detection)
- 24-hour asthma risk forecast
- Smart alert system
- Doctor notification (concept/prototype)

---

## 📱 App Modes
1. Without Device → Uses phone sensors and microphone  
2. With Device (ESP32) → Real-time monitoring  
3. Location-Based → AQI API  

---

## 🛠️ Tech Stack
- Antigravity App Builder
- JavaScript / Web Technologies
- AQI API
- ESP32 (optional)

---

## 🤖 AI Model
- Rule-based AI combining:
  - AQI + Temperature + Humidity  
  - User triggers  
  - Symptom patterns  

- Output:
  - 🟢 Low Risk  
  - 🟡 Medium Risk  
  - 🔴 High Risk  

---

## 🎯 Objective
To predict asthma attacks early and prevent emergencies.

---

## ⚠️ Disclaimer
This system provides early warning and does not replace medical advice.
